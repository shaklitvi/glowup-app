# GlowUp - AI Social Platform

## Deployment to Vercel (1 Click!)

### Click Here to Deploy:
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/shaklitvi/glowup-app&env=HUGGING_FACE_API_KEY&envDescription=Your%20Hugging%20Face%20API%20Key&envLink=https://huggingface.co/settings/tokens)

### OR Manual Deploy (3 Steps):

1. **Go to Vercel.com**
   - Sign up with your GitHub account

2. **Import Project**
   - Click "New Project"
   - Select "glowup-app" repository

3. **Add Environment Variable**
   - Set: `HUGGING_FACE_API_KEY`
   - Value: Your HF token from huggingface.co/settings/tokens
   - Click "Deploy"

Done! Your app will be live in 2-3 minutes.

## Get Your API Key

1. Visit https://huggingface.co
2. Sign up (Free!)
3. Go to Settings → Access Tokens
4. Create a new token
5. Copy and paste into Vercel Environment Variables
